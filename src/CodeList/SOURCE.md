## Case names

Case names come from the code: characters outside `[A-Za-z0-9]` become `_`, and a name that does
not start with a letter gets the prefix `C_` (`'380'` is `InvoiceTypeCode::C_380`, `'1I'` is
`UnitCode::C_1I`, `'VATEX-EU-79-C'` is `VatExemptionReason::VATEX_EU_79_C`). `VatCategory` uses
readable names instead (`'AE'` is `VatCategory::ReverseCharge`, `'S'` is
`VatCategory::StandardRate`).
