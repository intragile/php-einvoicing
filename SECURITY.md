# Security Policy

Developed and maintained by [IntrAgile Kft.](https://intragile.eu)

## Reporting a vulnerability

Please report security issues privately to **info@intragile.eu** rather than opening a public
issue. Include the affected version and, if possible, a sample invoice file and steps to
reproduce. You will receive a reply within a few working days.

## Scope

This package parses invoices received from third parties. Reports are especially welcome for:

- XML external entity (XXE), DOCTYPE or entity-expansion issues when reading UBL or CII;
- inputs that make the reader use unbounded memory or time;
- incorrect amounts caused by rounding or decimal handling;
- output that escapes characters incorrectly and changes the meaning of a written invoice.
